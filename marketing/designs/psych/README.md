# Standard Enterprise Governance (SEG): حزمة علم نفس الإقناع

بريف الـCEO (4 نوفمبر 2026). يولّدها [`scripts/psych-ads.js`](../../../scripts/psych-ads.js)، والمعرض في [`index.html`](index.html).

**البراند:** navy `#0D1B3E` وcyan `#1BB7CD` وأبيض، وأحمر إنذار `#C0392B` لعلامات الخطر الصغيرة فقط (نقطة، شارة، علامة سالب). بلا ذهبي. عربي RTL، ومع كل تصميم CTA «فحص مجاني في دقائق · seg-audit.com» وعلامة MFT.

**المقاسات:** كل تصميم مربع 1080×1080 وستوري 1080×1920، و1200×630 حيث يناسب. بصيغتي JPG وWebP.

**قاعدة البيانات:** لا بيانات حقيقية لـMFT أو لأي عميل. كل رقم دفاتر داتا اختبارية معلَّمة «مثال توضيحي». الاستثناءان: أرقام برنامج الأعضاء المؤسِّسين (من `site.config.js → founding`)، وعدد الاختبارات (من `platform-facts.js`). أعد التوليد بعد أي تغيير فيهما.

| التصميم | المبدأ | الفكرة |
|---|---|---|
| `1-loss-aversion/` | Loss aversion | الخسارة أثقل من المكسب: خطأ صغير اليوم يكبر حتى الإقفال. الدائرة تكبر مع الوقت، والأحمر نقطة البداية وشارة النهاية فقط. المبالغ مثال توضيحي. |
| `2-curiosity-gap/` | Curiosity gap (Zeigarnik) | العقل لا يترك قائمة ناقصة: ٥ بنود، ٣ ظاهرة و٢ مموّهة، والكشف الوحيد هو الفحص المجاني. البنود هي مؤشرات الفحص الحقيقية، بلا أرقام. |
| `3-shocking-specificity/` | Shocking specificity | رقم دقيق محدد يُصدَّق ويُتذكَّر أكثر من وصف عام: خزينة بالسالب −١٨٬٧٤٧٬١٠٦ ج.م، معلَّم «مثال توضيحي · داتا اختبارية». علامة السالب والنقطة فقط بالأحمر. |
| `4-scarcity-proof/` | Scarcity + social proof | ندرة حقيقية مع دليل: باقي 33 من 50، وانضمّت 17 شركة (من site.config.js → founding، حتى 2026-11-03). المقاعد الممتلئة بيضاء، ومقعدك سماوي. أرقام العرض المعلن، لا بيانات دفاتر. |
| `5-meta-authority/` | Meta authority | السلطة من الدليل لا من الادعاء: المنصة التي تراجع نفسها، +٧٬٩٠٠ اختبار آلي قبل كل تحديث (من كود المنصة، 2026-10-26). استُخدمت الصياغة المعتمدة بدل «الوحيدة» لأنها ادعاء تفضيل مطلق بلا دليل. |
| `6-anchoring/` | Anchoring | المرساة السعرية: تكلفة مفاجأة الإقفال (+٢٥٠٬٠٠٠ ج.م، مثال توضيحي) بجانب الفحص المجاني (٠ ج.م) فيبدو القرار بديهيًا. |
| `7a-pattern-break-graffiti/` | Pattern break: graffiti v2 | كسر النمط في الـfeed: جرافيتي على خرسانة بإضاءة علوية، ورذاذ ونقاط طلاء، وستنسل عين SEG، وعلامة «!» حمراء صغيرة. |
| `7b-pattern-break-palm/` | Pattern break: palm v2 | كسر النمط: يد مرسومة بظل وعمق وكُم navy بخط سماوي، و«راجع دفاترك قبل الإقفال» بخط قلم، ودائرة قلم حمراء صغيرة حول «!». |
| `8-hawk-eye/` | Vigilance: the hawk’s eye | عين الصقر (رمز MFT) كعنصر رقابة: قيود الدفتر منعكسة في القزحية، ونقطة حمراء صغيرة رصدتها العين. «عين على دفاترك. كل يوم.» |
