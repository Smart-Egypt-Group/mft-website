# SEG Audit: guerrilla "attention" pack

Brief from the CEO (3 Nov 2026). Generated by [`scripts/guerrilla-ads.js`](../../../scripts/guerrilla-ads.js). Open [`index.html`](index.html) to see the gallery.

These are **stylized, code-generated** designs. Nothing in them is a photo, and no real person appears: the hand is a flat illustration. If a style ever needs to look photographic, it needs a real photo shoot.

Brand: navy `#0D1B3E`, cyan `#1BB7CD`, white, no gold. Arabic RTL. Each frame carries the small CTA «فحص مجاني في دقائق · seg-audit.com» and the MFT mark. Every line comes in two sizes, square `1080×1080` and story `1080×1920`, as both JPG and WebP.

**Fonts.** The hand lettering uses fonts that ship with macOS: Waseem for the spray and marker, Farisi for the pen, and Bradley Hand for the Latin domain. The UI type is Cairo. On another OS the hand lettering falls back to different fonts, so render on a Mac:

```bash
PLAYWRIGHT_PATH=<path to playwright> node scripts/guerrilla-ads.js [filter]
```
