# ورقة شروط اتفاقية الشراكة (مسودة للاعتماد)

**الحالة:** مسودة. **الأرقام بين [ ] مقترحة** من [03-partner-program.md](../03-partner-program.md) وتحتاج اعتماد الـCEO، ثم مراجعة قانونية في مصر والسعودية، قبل إرسالها لأي شريك.

| البند | الشرط |
|---|---|
| الأطراف | Modern Financial Technology (MFT) و {الشريك} |
| المسار | ☐ إحالة ☐ وكيل / موزّع ☐ شريك ممارسة |
| المنطقة | {مصر / السعودية / …}، غير حصرية |
| المدة | سنة، تتجدد تلقائيًا؛ إنهاء بإخطار 60 يومًا |
| المستوى | يبدأ «مسجّل»؛ يُراجَع كل ربع بالشروط المنشورة في البرنامج |
| **عمولة الإحالة** | [15% / 20% / 25%] من صافي المبالغ **المحصّلة** من العميل في أول 12 شهرًا؛ و[10%] في السنتين 2 و3 للمستويين معتمد ومميّز طالما الشريك يخدم الحساب. تُصرف شهريًا عن الشهر السابق، بعد التحصيل. لا عمولة على الضرائب ولا على المبالغ المستردة |
| **خصم الوكيل** | [20% / 30% / 35%] من سعر القائمة الساري. الشريك يفوتر العميل ويتحصّل منه، ويدفع لـMFT خلال 30 يومًا من فاتورة MFT بصرف النظر عن تحصيله من العميل |
| **شريك الممارسة** | حساب المؤسسات باسم الشريك؛ سعر جملة لكل شركة نشطة شهريًا [يحدده الـCEO]؛ مقاعد إضافية بسعر القائمة ناقص خصم المستوى |
| حساب العمولة | من فواتير Odoo المحصّلة. **محرّك الإحالة في المنصة يحسب 20% على أول فاتورة فقط ولا يُستخدم للصرف حتى يُعدَّل** |
| تسجيل الصفقة | بالنموذج أو البريد؛ قبول أو رفض خلال يوم عمل؛ حماية [60 / 90 / 120] يومًا حسب المستوى؛ لا يسري على حساب في pipeline نشط لـMFT أو حساب ABM T1 مسمّى |
| التسعير للعميل | الوكيل حر، دون إعلان سعر أقل من (القائمة − خصمه) إلا بموافقة MFT |
| الاعتماد النهائي للتقارير | من مراجع MFT باسمه. للشريك الاعتماد الداخلي. لا يُقدَّم التقرير كرأي مراجعة |
| العلامة التجارية | Co-branding بموافقة MFT على كل مادة. لا white-label حتى يُتاح في المنتج ويُعتمد |
| البيانات | بيانات كل عميل ملك العميل. الشريك يلتزم بقانون حماية البيانات المعمول به، ولا يرفع بيانات عميل دون موافقته. اتفاقية معالجة بيانات مرفقة |
| الاستقلال المهني | الشريك يقرّ بأنه لا يتقاضى عمولة أو خصمًا على عميل يراجع قوائمه المالية، ويخطر MFT بذلك عند التسجيل |
| التسويق | لا يذكر الشريك أرقامًا أو قدرات غير منشورة من MFT، ولا أسماء عملاء دون موافقتهم الكتابية |
| MDF | للمستوى «مميّز» فقط: حتى [5%] من إيراد الشريك في الربع السابق، لكل نشاط بموافقة الـCEO المسبقة، ويُصرف بعد إثبات التنفيذ |
| عدم الاستمالة | لا يستميل أي طرف موظفي الآخر خلال المدة و6 أشهر بعدها |
| انتقال العميل | يحق للعميل الانتقال لحساب مباشر مع MFT؛ يحتفظ الشريك بعمولته المتبقية عن مدة الإحالة |
| القانون والنزاع | [القانون المصري، ومحاكم القاهرة / أو التحكيم]؛ للسعودية ملحق خاص |
