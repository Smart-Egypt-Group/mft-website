# SEG Audit sales playbook (B2B SaaS 2026)

**التسمية (الـCEO):** الشركة الأم MFT ← المنصة **SEG — Standard Enterprise Governance** ← المنتج **SEG Audit** (وحدة المراجعة المستمرة). في النصوص الطويلة (العروض، الورقة الواحدة، About) يُذكر الاسم الكامل للمنصة مرة على الأقل.

## الملخص

**المبدأ:**
- المنتج يؤهّل.
- الشريك يوزّع.
- المؤسس يبني الثقة.
- المبيعات تُغلق الصفقات الكبيرة بتأهيل صارم.
- كل حركة مربوطة برقم واحد من مرجع الـCEO.

**المرجع:**

| المقياس | الهدف |
|---|---|
| CAC | ≤ 2,500$ |
| ARPA | 6,000$ |
| NRR | ≥ 115% |
| الاسترداد | حوالي 6 أشهر |

**الحوكمة:** لا نشر ولا صرف ولا أرقام لشريك ولا تغيير على Odoo الحي إلا بموافقة الـCEO ([11](11-compliance-and-governance.md)). كل ما هنا مسودات وأصول جاهزة للتشغيل بعد الموافقة.

```
التسويق (المحتوى، الإعلانات، المؤسس)   الشركاء (مكاتب، شركاء Odoo)   ABM (مجموعات، مكاتب كبيرة)
            │                                   │                              │
            └─────────── فحص الميزان المجاني (الـwedge) ──────────────────────┘
                                   │
                         تفعيل داخل المنتج ← PQL
                                   │
                  Odoo CRM: المراحل + النقاط + MEDDPICC
                                   │
                        مدفوع ← توسّع (NRR) ← دراسات حالة
```

## ما يجب أن يعرفه كل بائع قبل أول مكالمة

تحقّقنا من كود المنصة في 3 نوفمبر 2026.

1. **الفحص المجاني من ملف الميزان يكشف:** عدم الاتزان، والأرصدة في غير جانبها، وتآكل حقوق الملكية، والتركّز. أما **الحسابات المعلّقة والقيود اليدوية والتواريخ الرجعية فتحتاج ربط Odoo أو القيود.** القرار #8 مفتوح.
2. **سعر المؤسِّس مدى الحياة غير مبني في الفوترة.** لا يُوعد به كتابيًا قبل القرار #3. المبني: عرض الإطلاق 50% من أول دورة.
3. **لا white-label ولا بوابة شركاء ولا ربط بنقرة** (معطّل). الاعتماد النهائي لمراجع MFT فقط.
4. **الأسعار بالجنيه** (التحصيل بالجنيه فقط)، و**ARPA 6,000$ أعلى من أي باقة لشركة واحدة في مصر**. الطريق: المؤسسات، والشركاء، والسعودية.
5. **Odoo Online لا يقبل موديولات مخصّصة.** عملاؤه يبدؤون برفع الميزان.
