# 06. إيقاع المبيعات اليومي والأسبوعي (مدمج مع التسويق)

يكمّل [01-operating-system.md](01-operating-system.md): نفس اليوم ونفس الوقف اليومي، مع كتل المبيعات. الـplaybook كاملًا في [`marketing/sales/`](../sales/README.md).

## الأدوار الإضافية

شخص واحد قد يحمل أكثر من دور. **فصل المهام:** من يُعدّ العرض أو العمولة لا يعتمدهما.

| الدور | يملك | يقيسه أسبوعيًا |
|---|---|---|
| **مسؤول الحساب (AE)** | PQL والفرص من المرحلة 3، والديمو، والعروض، وMEDDPICC | فرص جديدة، وتحويل المراحل، وCommit |
| **SDR / تطوير المبيعات** | تسلسلات Outbound، ومرشحي PQL، وتحديث النقاط اليومي، وحجز الاجتماعات | ردود إيجابية، واجتماعات محجوزة |
| **مدير الشركاء** | طلبات الشراكة، والاتفاقيات، والتمكين، وتسجيل الصفقات، ومكالمات pipeline الشركاء | شركاء نشطون، وفرص من الشركاء |
| **العمليات (RevOps)** | Odoo CRM: المطابقة اليومية مع المنصة، والـUTM، والحقول، والتقارير، والحسابات التحليلية لـCAC | جودة البيانات (% فرص كاملة الحقول) |
| **المؤسس** | 3 منشورات أسبوعيًا، و20 دقيقة تعليقات يوميًا، وDMs، وحسابات T1، والمشتري الاقتصادي في الصفقات الكبيرة | محادثات مؤهّلة، واجتماعات T1 |
| **الـCEO** | اعتماد كل صرف أو نشر أو أرقام شريك أو خصم ([11](../sales/11-compliance-and-governance.md)) | — |
