# 04. Daily monitoring checklist

Two passes a day (09:15 and 21:00 Cairo). Morning pass is the full list; the evening pass is the lines marked ◐. Record each pass in the day's row of the monitoring sheet (one tab per week) and log any action.

## Every morning, before the platforms

- [ ] Seats filled today (internal tally, never published while the counter is off): ___ of 50
- [ ] app.seg-audit.com/ar/signup and /en/signup open and the form submits (one test per week, label the test account "delete me")
- [ ] www.seg-audit.com/ar/founding-members/ loads; launch bar visible
- [ ] New sign-ups in the last 24h: ___ → all in CRM with source + UTM?
- [ ] ◐ Unanswered DMs / comments across all platforms: ___ (target 0 by end of day)

## LinkedIn (company page + founder profile)

- [ ] ◐ Comments on the last 3 posts answered
- [ ] Impressions, reactions, comments, reposts, link clicks for yesterday's post → content log
- [ ] Follower change (company page)
- [ ] DMs and InMail answered; prospects tagged in CRM
- [ ] Founder's post: reply to every comment from a finance decision-maker within the first hour

## Facebook page (Modern Financial Technology)

- [ ] ◐ Comments, Messenger, and comments on ads (ads comments appear in Meta Business Suite → Inbox)
- [ ] Reach, link clicks, shares for yesterday's post → log
- [ ] Hide spam; never delete criticism
- [ ] Page rating / reviews: any new one answered

## Instagram (@modernfintech)

- [ ] ◐ DMs (including the "Requests" folder) and comments
- [ ] Story views and link taps for yesterday's stories; reach and saves for feed posts → log
- [ ] Link in bio points to the current founding page with UTM
- [ ] Story highlight «الأعضاء المؤسِّسون» updated with the latest seat story

## X

- [ ] ◐ Replies and mentions answered
- [ ] Impressions, link clicks, reposts → log
- [ ] Search «SEG Audit» and «seg-audit» for mentions

## YouTube

- [ ] Comments on Shorts and videos answered (YouTube Studio → Comments)
- [ ] Views, average view duration, CTR of the thumbnail (if a long video is up) → log
- [ ] Channel banner and links current

## TikTok

- [ ] ◐ Comments answered in the first hour after posting (the algorithm weights early replies)
- [ ] Views, 2-second view rate, average watch time, profile visits → log
- [ ] Link in bio current (if the account has the feature)

## Meta Ads (Ads Manager)

- [ ] ◐ Spend today vs pace (B / 7): ___ / ___ (hard stop at 1.3 ×)
- [ ] Delivery status: any ad set "Learning limited", rejected ad, or account warning?
- [ ] Per ad set: results, cost per result vs T, CTR (link), frequency
- [ ] Apply the pause/scale rules from [03-paid-ads.md](03-paid-ads.md); log every change
- [ ] Instant Form leads exported to CRM (phase 1)
- [ ] Ad comments answered

## TikTok Ads

- [ ] ◐ Spend vs pace
- [ ] Per ad group: cost per result, CTR, 2-second view rate, 6-second view rate
- [ ] Rejected creatives or policy notices
- [ ] Apply rules; log changes

## Track B (founding members)

- [ ] Today's touchpoints from the track B plan done; CRM activity logged per member
- [ ] Any member with a support issue: owner assigned, answer within 1 working day
- [ ] Consent forms received today (testimonial / case study / listing): filed and noted in CRM

## End of the evening pass

- [ ] Comment and DM queue at zero, or handed to tomorrow's stand-up
- [ ] Anything that breaks a rule (negative surge, policy notice, broken link) escalated to the campaign owner with a screenshot
